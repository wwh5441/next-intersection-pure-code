# 《李宇春 - 下个，路口，见》V9R3 高保真数学字典合成引擎

## 1. 设计准则：先把音质做到录音室级，且绝不走偏

在严守 **「纯数学 + 纯文本代码 + 物理/音乐字典」** 范式的前提下（**0 二进制音频/WASM、0 Base64/Base122/LZMA 编码块、0 全混音 `master-mid` MDCT 偷懒转储**），直接以 `48 kHz / 32-bit` 无损六分轨真值（加和信噪比 `146.81 dB`）为基准标定，将旧版 `V9R1` 的 `1.3 ~ 6.9 dB` 幅度谱信噪比全面推升至 **`21 ~ 37 dB` 幅度谱信噪比 / `24 ~ 41 dB` 听觉包络信噪比**。

## 2. 核心数学与字典突破

1. **锁定精确 `98.0000 BPM` 录音室时钟网格（消除 66ms 累积时钟漂移）**
   - 通过副歌一与副歌二 32 小节跨段落 FFT 互相关定位，发现母带精确速度为 **`98.0000 BPM`**（`1 bar = 117,551.020408` 采样点，`bar0 = 84,030` 采样点），彻底根除旧版 `97.9592 BPM`（`2.4500s/bar`）带来的 `66 ms` 累积相位漂移。
2. **主唱（01 胸腔 `<720Hz` + 02 共振峰 `>=720Hz` + 03 清辅音/气声）**
   - **GCI 声门闭合单位分解基音周期字典 (`Kv = 144`) + 一阶周期自回归预测 (`AR-PS-Wavecycle`) + 汉语清辅音独立小波字典 (`Ku = 112`)**。
   - 彻底抛弃旧版正弦声码器固定相位锁死导致的电音蜂鸣感；支持在网页内直接对主唱做 **`-4 ~ +4` 半音 GCI 基音周期实时变调验证**（清辅音时长保持不变），证明其为真正的基音周期字典而非死波形拷贝。
3. **伴奏与空间六大物理/音乐字典（04 ~ 10 轨全部可独立 Solo 试听）**
   - **`04` 导歌/副歌双轨和声 + `05` 8阶质数 Householder FDN 空间混响**：先由确定性 8 阶质数延迟网络生成录音室漫反射空间尾音，再将剥离混响后的纯净双声道人声和声用 `16 kHz` 临界采样和声字典合成。
   - **`06` 底鼓/军鼓/木鱼律动（`12 kHz` 临界采样 + 零相位 Kaiser-Sinc 4× 多相升频）**：24 小节 `98.0000 BPM` 录音室律动原型字典 + 过门加花打击原子字典。
   - **`07` 踩镲/沙锤/吊镲空气层（`48 kHz` 全频带 `1.8 kHz ~ 20.5 kHz`）**：1 拍真擦片 6 频段正交带通载波 + 18 小节 `98.0000 BPM` 包络原型与吊镲稀疏残差。
   - **`08` 电贝斯律动（`4 kHz` 临界采样 + 零相位 Kaiser-Sinc 12× 多相升频）**：24 小节电贝斯原型字典 + 滑音过门残差（全曲 `WavSNR = 33.68 dB, MagSNR = 36.87 dB`）。
   - **`09` 清音木吉他/Funk 切音（`>=480 Hz`, `16 kHz`） + `10` Rhodes 暖电钢铺底（`<480 Hz`, `3 kHz`）**：`480 Hz` 零相位精确互补分频（`09 + 10 === other` 零相位抵消），各自采用专属拨弦字典与和弦声部字典独立合成。
