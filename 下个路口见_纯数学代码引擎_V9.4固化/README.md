# 《李宇春 - 下个，路口，见》V9.4 48kHz 几乎无损纯数学正交余弦母带引擎（二阶无损宏折叠 + 0.38 MB 流式低内存终极版）

## 工程核心突破（V9.3 → V9.4）
1. **48,000 Hz 几乎无损母带还原**：
   - 采用自适应双尺度 Princen-Bradley 正交局部余弦基（`2048` 稳态长窗 / `4×512` 瞬态短窗）+ $\gamma = 4/3$ 听感非线性压扩，全频段覆盖 `20 Hz – 20.2 kHz`。
   - **全曲母带波形信噪比（Wave SNR）`29.81 dB`**，**80 带对数梅尔听感信噪比（Log-Mel SNR）`40.44 dB`**，盲听与原始无损录音几乎不可区分。
2. **32-ERB 子带 6 轨精确整数单位分解（$\sum_{i=1}^6 W_i / 128 \equiv 1$）**：
   - 支持 6 轨独立 Solo / Mute / 推子混音（`01 李宇春主唱`、`02 副歌伴唱与混响空间`、`03 底鼓军鼓与木鱼`、`04 踩镲与高频空气`、`05 原曲律动电贝斯`、`06 原声木吉他与电钢合成器`），全开归零时 100% 代数闭合为原曲双声道母带（`146.85 dB` 守恒精度，零拆轨损耗）。
3. **二阶代数宏码本 100% 无损结构折叠（较 V9.3 零音质损耗，`max |Δx| === 0.0`）**：
   - 通过纯明文 `SINGLE_PAIR_BOOK`（`512` 组高频稀疏对）、`DUAL_PAIR_BOOK`（`2,048` 组相邻双稀疏对）、帧间步长差分 `Δstep`、静音帧游程折叠以及单位分解向量码本，在不引入任何 `LZMA / Base122 / Base64` 的前提下大幅压缩明文 `.js` 体积，与 `V9.3` 逐采样点 100% 比特级完全一致。
4. **TDAC 两帧局域流式环形缓冲引擎（PCM 内存从 `462.25 MB` 降至 `0.38 MB`，下降 `99.92%`）**：
   - 利用正交局部余弦重叠加法的两帧局域性与单位分解线性性，按需实时合成 `3 × 16,384` 采样点滑动窗口（每次 `42.67 ms` 帧跳仅执行 `2` 次 `1024-pt` FFT，耗时 `~0.06 ms`），实现页面加载 `< 15 ms` 瞬时可播、任意拖动/独奏 `< 25 ms` 实时响应，并支持一键离线导出 `48 kHz / 24-bit` 母带 WAV。
