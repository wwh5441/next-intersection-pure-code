# 《李宇春 - 下个，路口，见》V9.3 48kHz 几乎无损纯数学正交余弦母带引擎（展开式基线固化版）

## 工程定位
- **零外部音频 / 零二进制压缩壳**：严禁任何 `.mp3/.wav/.bin/.npz/.lzma/.gz` 文件，严禁 `LZMA`、`Base122`、`Base64` 或不透明长字符串，100% 由人类可读纯明文 JavaScript 数学数组与显式三角函数正交基合成。
- **48,000 Hz 几乎无损母带还原**：采用自适应双尺度 Princen-Bradley 正交局部余弦变换（`2048` 稳态长窗 / `4×512` 瞬态短窗）+ $\gamma = 4/3$ 听感非线性压扩，全频段覆盖 `20 Hz – 20.2 kHz`。
- **32-ERB 子带 6 轨精确整数单位分解（Partition-of-Unity）**：
  $$\sum_{i=1}^{6} \frac{W_i(t, b)}{128} \equiv 1.0000000$$
  支持 6 轨独立 Solo / Mute / 推子混音（`01 李宇春主唱`、`02 副歌伴唱与空间混响`、`03 底鼓军鼓木鱼`、`04 踩镲与高频空气`、`05 电贝斯`、`06 原声木吉他与电钢合成器`），当 6 轨同处 `0.0 dB` 时 100% 精确闭合为原曲双声道母带，彻底消除 AI 分轨串扰与相位损耗。
- **V9.3 基线特征**：采用**未折叠的显式稀疏 `(zeroSkip, quantVal)` 对**与全曲 6 轨双声道 Web Worker 预合成架构（作为 `V9.4` 无损代数折叠与流式低内存优化前的母带级精确基准）。
